# Rapport — TP3

## Points clés

### 1. dom

Plutôt que de manipuler directement les éléments du DOM pour les cacher ou les modifier, on filtre/modifie d'abord le tableau de données, puis on réaffiche tout depuis zéro. Le tableau est la seule source de vérité.

### 2. html dynamique

On peut créer du HTML dynamiquement avec createElement et les template literals
On peut générer des cartes HTML en JS en créant des éléments avec document.createElement() et en injectant du contenu avec des backticks qui permettent d'intégrer des variables directement dans la chaîne HTML.
